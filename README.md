# Forensic Quiz – Pink Aesthetic

An interactive, responsive Forensic Science quiz built with **HTML, CSS and JavaScript**.

## Features
- 15 multiple-choice questions across forensic science topics
- Instant answer feedback and explanations
- Progress bar and question counter
- Final score and percentage
- Restart quiz option
- Responsive layout for mobile and desktop
- No frameworks or installation required

## Topics
Fingerprints, DNA forensics, crime scene investigation, forensic ballistics, toxicology, questioned documents, digital forensics, forensic biology, anthropology and entomology.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start the quiz.

## Deploy with GitHub Pages
1. Open your GitHub repository.
2. Go to **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Click **Save**.
6. Wait for GitHub Pages to publish your site. The website URL will appear in the Pages section.
